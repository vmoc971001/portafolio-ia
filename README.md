# Portafolio de proyectos con IA

Tres proyectos de automatización con IA aplicada a problemas de negocio reales. Cada carpeta explica el problema, lo que construí, la arquitectura, las decisiones técnicas y, cuando la confidencialidad lo permite, fragmentos de código anonimizados.

| Proyecto | Qué resuelve | Contenido |
|---|---|---|
| [Agente inmobiliario por WhatsApp](agente-inmobiliario-whatsapp/) | Atención automatizada de interesados, inquilinos y propietarios por un único número de WhatsApp, integrada al CRM, más un agente interno por Telegram para el equipo. | README, detalle de workflows, ejemplos SQL/JS |
| [Relevamiento de precios en góndola con IA](relevamiento-precios-ia/) | Bot de Telegram que lee carteles de precios con un modelo de visión, con confirmación humana y controles para que la base no se llene de errores. | README, detalle de workflows, ejemplos SQL/JS |
| [Copiloto de decisiones de precio con IA](copiloto-precios-ia/) | Recomendaciones de precio con razonamiento visible, considerando coproducción y vencimiento de productos perecederos. | README (diseño, sin código por confidencialidad) |

> El código completo y los datos de los proyectos pertenecen a sus respectivos clientes o empleadores; aquí se publica solo lo que se puede compartir.
